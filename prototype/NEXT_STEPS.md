# 다음에 손볼 것 (v0.3 기준)

실제 웹캠으로 확인해야 하는 항목과, 이미 알고 있는 한계입니다. 확인한 사람이 결과를 옆에 적어 주세요.

## 웹캠으로 확인할 것
- [ ] 가위/바위/보 판정 임계값(`gesture.js`의 `(r - 0.1) / 0.2`)이 실제 손에서 맞는지. 손을 카메라 쪽으로 기울이면 손가락이 짧아 보여 "보"가 "바위"로 갈 수 있음.
- [ ] 제안 방식의 또렷함 기준 0.35, 흔들림 기준 0.12가 너무 엄격하거나 느슨하지 않은지.
- [ ] 손 놓침 0.4초 → 안내, 복구 0.6초가 체감상 자연스러운지.
- [ ] 노트북 내장 카메라에서 fps가 20 아래로 떨어지는지 (기술 정보의 `fps`).
- [ ] 왼손·오른손, 어두운 조명, 카메라와의 거리 1m에서도 되는지.

## 알고 있는 한계
- 엄지는 판정에서 뺐다. 엄지를 편 "바위"도 바위로 본다.
- 손이 두 개 보이면 첫 번째 손만 쓴다. 사용할 손 선택 기능은 아직 없다.
- 손 인식 모듈을 CDN에서 받는다. 오프라인 실행본은 아직 없다 (README 마지막 절 참고).
- 고양이 동작은 대기·인사·기다리기·기뻐하기·두리번거리기·하이파이브·쉬기이며 모두 CSS 애니메이션이다. 스프라이트 시트는 아직 없다.
- 5분 코스, 나머지 게임, 방 꾸미기, 계정은 없다.
