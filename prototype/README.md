# MotionBrain 프로토타입 v0.3 · 고양이의 변덕

가위바위보 60초 한 판에 고양이 한 마리, 손 놓침 안내, 하이파이브를 붙인 첫 실행본입니다.
아이디어 노트의 "예상 결과물" 3장면(플레이 / 손이 안 보일 때 / 완료)을 실제로 돌아가게 만든 것입니다.

## 실행

빌드가 없습니다. 폴더를 로컬 서버로 열면 됩니다. (파일을 더블클릭해 `file://`로 열면 모듈이 막혀서 안 됩니다.)

```bash
cd prototype
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

- **카메라로 하기**: "고양이 깨우기 · 카메라 켜기" → 권한 허용. 손 인식 모듈(MediaPipe)은 처음 한 번 인터넷에서 받아옵니다.
- **웹캠 없이 보기**: "웹캠 없이 키보드로 해보기". 키는 화면 오른쪽에 나옵니다.
  `1` 가위 · `2` 바위 · `3` 보 (누르고 있는 동안 유지) · `4` 흐린 손 모양 · `0` 손 숨기기/보이기 · `Space` 중립 손

## 흐름

시작 → 손 인사(손이 0.8초 보이면 통과) → 연습(보, 바위 한 번씩) → 60초 놀이 → 결과(하이파이브 또는 건너뛰기 → 완료 도장·보상) → 한 번 더

## 입력 방식 3종 (상단 선택)

같은 손 추적 결과를 놓고 확정 규칙만 다릅니다. 제안서 6.1절의 비교 기준입니다.

- **즉시 확정 (B0)**: 손 모양이 바뀐 첫 프레임에 바로 확정. 손을 바꾸는 중간에 잘못 눌리는 걸 보여주는 하한선.
- **유지 확정 (B1)**: 같은 모양을 300ms 유지하면 확정. 확정한 모양을 풀어야(다른 모양·중립·손 내림) 다음 입력. 주 비교 기준.
- **제안 방식 (P)**: 유지 + 또렷함 + 흔들림 조건 + 재입력 준비 + 손 놓침 복구. 손이 0.4초 안 보이면 게임을 멈추고 안내하고, 다시 보이면 0.6초 준비 뒤 같은 문제부터 이어갑니다.

"기술 정보" 버튼을 켜면 프로필 이름, 임계값, fps, 현재 상태, 시행·정답·오답·무응답·손 놓침·거짓 입력 수가 아래에 표시됩니다.

## 폴더

```
prototype/
  index.html          화면 구조와 손 모양 아이콘
  css/style.css       스타일과 고양이 애니메이션
  js/config.js        시간·경로 설정
  js/camera.js        카메라 권한·스트림 (저장·전송 없음)
  js/tracker.js       MediaPipe 손 추적 + 키보드 데모 소스
  js/gesture.js       관절 21개 → 가위/바위/보 후보 + 또렷함
  js/input-engine.js  입력 품질·이벤트 계층 (B0 / B1 / P 프로필)
  js/game-rps.js      고양이의 변덕 규칙·채점·일시정지
  js/cat.js           도형으로 그린 고양이 (표현만 담당)
  js/storage.js       완료 횟수·보상 로컬 저장
  js/main.js          이용 흐름 연결
```

## 저장하는 것, 저장하지 않는 것

- 저장: 완료 횟수, 잠금 해제한 장식 (브라우저 localStorage, "완료 기록 초기화"로 삭제)
- 저장하지 않음: 카메라 영상, 프레임, 관절 좌표, 시행 로그. 어디로도 전송하지 않습니다.

## 오프라인 실행본을 만들 때

`js/config.js`의 `mediapipe` 세 경로(bundle, wasm, model)를 로컬 복사본 경로로 바꾸면 인터넷 없이 돕니다.
